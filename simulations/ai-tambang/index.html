Bagian 3 — Latihan Praktik Kaggle
Ikuti langkah-langkah berikut di Kaggle Notebook (~40 menit)
1
Buka Notebook & Copy
Klik "Buka Notebook Latihan" → login Kaggle → klik "Copy & Edit" untuk membuat salinan Anda sendiri.
2
Load Data
Jalankan cell pertama untuk load dataset 737K baris data pertambangan.
df = pd.read_csv('/kaggle/input/quality-prediction-in-a-mining-process/MiningProcess_Flotation_Plant_Database.csv', decimal=',') print(df.shape) df.head()
3
Eksplorasi & Siapkan Fitur
Cek missing values, statistik, lalu pilih 7 variabel proses sebagai input model prediksi.
4
Latih & Bandingkan Model
Jalankan Linear Regression vs Random Forest — lihat perbedaan RMSE dan R².
5
Visualisasi & Eksperimen
Plot scatter prediksi vs aktual, feature importance, lalu modifikasi di area eksperimen mandiri.
