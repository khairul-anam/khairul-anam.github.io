Dataset berisi data hasil uji laboratorium komposisi campuran beton (semen, air, abu terbang/fly ash, dll) beserta hasil kuat tekan (MPa) pada berbagai umur curing. Tujuan: memprediksi kuat tekan beton tanpa harus menunggu proses curing 28 hari di lapangan.

Bagian 3 — Latihan Praktik Kaggle
Ikuti langkah-langkah berikut di Kaggle Notebook (~40 menit)
1
Buka Notebook & Copy
Klik "Buka Notebook Latihan" → login Kaggle → klik "Copy & Edit" untuk membuat salinan Anda sendiri.
2
Load & Rapikan Data
Jalankan cell pertama untuk load data uji beton, lalu rapikan menjadi 9 kolom utama dengan nama yang mudah dipahami.
path = '/kaggle/input/datasets/ahmeduzaki/concrete-compressive-strength-dataset/Concrete Compressive Strength.csv' df = pd.read_csv(path) df = df.iloc[:, :9] df.columns = ['Semen','Terak','FlyAsh','Air','Plastis','BatuKasar','BatuHalus','Hari','Kekuatan']
3
Eksplorasi & Visualisasi
Lihat hubungan tiap bahan campuran (Semen, Terak, Batu Kasar, dst) terhadap kuat tekan beton lewat scatter plot dan nilai R².
4
Latih & Bandingkan Model
Jalankan dan bandingkan beberapa algoritma — Random Forest, SVM, Neural Network (MLP), Linear Regression, hingga Deep Learning — lihat mana yang paling akurat (R² tertinggi).
5
Coba Sendiri!
Ganti angka komposisi campuran (Semen, Air, Hari, dll) untuk memprediksi kuat tekan beton tanpa perlu menunggu 28 hari curing di lapangan.
🎉 Selamat! Anda baru saja membangun model ML pertama untuk memprediksi kuat tekan beton!
